REQ-002: Percentage Calculation

The Calculation Service shall support percentage calculations.

FR-001:
The percentage operation shall accept a numeric value and a numeric percentage value.

FR-002:
The percentage result must be calculated using the following formula:

(value * percentage) / 100

VR-001:
The percentage value must be validated before calculation.

VR-002:
The percentage value must be between 0 and 100 inclusive.

Negative percentage values must be rejected.

Percentage values greater than 100 must be rejected.

HR-001:
Percentage calculations must NOT be stored in HistoryService because percentage calculations are considered temporary calculations.

AR-001:
Every successful percentage calculation must generate a SUCCESS event using AuditService.

AC-001:
Percentage calculation must continue to use the existing InputValidator for numeric input validation.

AC-002:
The implementation must not modify the behavior of existing addition, subtraction, multiplication, or division operations.
