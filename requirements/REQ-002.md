REQ-002: Percentage Calculation

The Calculation Service shall support percentage calculations.

The percentage operation shall accept a numeric value and a numeric
percentage value.

The result shall be calculated as:

(value * percentage) / 100

All input values must be validated using the existing InputValidator.

Every successful percentage calculation must be recorded using
HistoryService.

Every successful percentage calculation must generate a SUCCESS
audit event using AuditService.

The implementation should reuse the existing Calculator architecture
and must not bypass existing validation, history, or auditing behavior.
